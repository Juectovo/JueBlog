【背景与决策】
GitHub Pages 是纯静态托管，无法运行 JueBlog 的 26 个 API 路由、数据库查询与登录会话——技术不可行。已确认方案：**Vercel 线上站（https://jueblog-juectovo.vercel.app，已 Ready）作为体验入口，把 GitHub 仓库 README 打磨成完整的开源展示页**，让访客「看得到亮点 + 点链接可体验 +  clone 下来能跑」。

【执行步骤】（共 6 步，预计一次完成）

1. **截图收集**（需要 dev server 最后在线一次）
   - 用浏览器对 localhost:3000 六个核心页面截图：首页、博客广场、文章详情、个人主页（热力图）、好友页、群组详情
   - 存入 `docs/screenshots/`（home.png / explore.png / post.png / profile.png / friends.png / groups.png）

2. **暂停本地服务器**
   - `taskkill //F //IM node.exe`——满足「暂停 localhost:3000」，此后不再启动

3. **重写 README.md**（开源展示模板，核心交付物）
   - 居中：JueBlog + Slogan + 徽章（Next.js 14 / TypeScript / Prisma / License MIT / 🌐 在线体验）
   - 「在线体验」醒目入口：https://jueblog-juectovo.vercel.app（说明用 GitHub 登录即可玩全部功能）
   - 截图展示区（引用第 1 步的图片）
   - 功能清单：GitHub OAuth/魔法链接/密码三通道认证、Markdown 博客（TOC/评论/点赞收藏）、好友系统（申请/动态流）、群组圈子（文章墙/分享）、创作热力图、RSS 订阅、博客环、AI 摘要、PWA、Cmd+K 搜索
   - 技术栈表 + 项目结构树
   - **本地运行四步**：clone → `cp .env.example .env.local` 填变量 → `prisma:push + db:seed` → `pnpm dev`
   - **环境变量表**（逐项说明；特别标注 Resend API Key 属服务端机密：只存 .env.local 与 Vercel 后台，严禁入仓库；GitHub Pages 无服务端环境变量——本项目不适用 Pages 的原因）
   - 部署说明：Vercel 导入 + 指向 docs/DEPLOY.md；GitHub Pages 不可行的技术解释
   - API 概览（链接 docs/api.md）+ License
4. **新增 LICENSE**：MIT（Copyright (c) 2026 Juectovo）
5. **提交并推送**：`git add README.md LICENSE docs/screenshots` → commit「docs: 开源 README + 截图 + LICENSE」→ push（网络抖动则直连/代理重试循环）
   - 推送前再次跑敏感信息检查（git grep 密钥/QQ 号模式）
6. **收尾验证**：GitHub 仓库页确认 README 渲染（gh api 拉 README 确认内容），本地服务器保持暂停状态

【不改动的部分】Vercel 部署与配置（已就绪且为线上体验入口）、所有业务代码、现有 .gitignore（已验证 .env.local/密钥被忽略）。
